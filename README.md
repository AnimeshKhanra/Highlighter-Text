# 🖍️ Web Highlighter — Chrome Extension

A lightweight, powerful tool to highlight text on any webpage across the web. Follow the instructions below to load and test the extension locally in your browser.

---

## 🚀 How to Install (Manifest V3)

Follow these quick steps to load the extension into Google Chrome using Developer Mode:

### Step 1: Extract the Files
*   **Unzip** the downloaded folder onto your computer.
*   Make sure you know where the folder is located (e.g., your Desktop or Downloads folder).

### Step 2: Open Extensions Page
*   Open **Google Chrome**.
*   In the URL bar, type `chrome://extensions` and press **Enter**.
*   *Alternative:* Click the **Puzzle Piece icon** 🧩 in the top-right corner of Chrome and select **Manage Extensions**.

### Step 3: Enable Developer Mode
*   Look at the **top-right corner** of the Extensions page.
*   Toggle the **Developer mode** switch to **ON** 🟢.

### Step 4: Load the Extension
*   Look at the **top-left corner** of the page.
*   Click the **Load unpacked** button.
*   Select the unzipped folder that contains your `manifest.json` file.

---

## 🎉 You're All Set!

1. Click the **Puzzle Piece icon** 🧩 in your Chrome toolbar.
2. Find **Web Highlighter** and click the **Pin icon** 📌 to keep it visible.
3. Open any website, select some text, and start highlighting!

> ⚠️ **Note:** Chrome does not allow extensions to run on default internal pages like `chrome://` settings or the Web Store. Test your extension on a live public website (like Wikipedia or a news site).
